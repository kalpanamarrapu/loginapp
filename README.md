# 🚀 LoginApp – Full Stack Task Management Web Application

A full-stack web application built using **Spring Boot, Spring Security, and MySQL** that allows users to register, log in, and manage their tasks securely.

---

## 🌐 Live Demo

👉 https://loginapp-7yv3.onrender.com

---

## ✨ Features

* 🔐 User Registration & Login Authentication
* 🔑 Password Encryption using BCrypt
* 📝 Add Tasks
* 📋 View Tasks
* ❌ Delete Tasks
* 👤 User-specific task management
* ☁️ Cloud Database integration (Railway MySQL)
* 🚀 Deployed on Render

---

## 🛠️ Tech Stack

**Backend**

* Java
* Spring Boot
* Spring Security
* Spring Data JPA

**Frontend**

* HTML

* MySQL (Railway Cloud)

## ⚙️ Installation & Setup

### 1. Clone the repository

```bash
git clone https://github.com/YOUR_USERNAME/loginapp.git
cd loginapp
```

---

### 2. Configure Database

Update `application.properties`:

```properties
spring.datasource.url=jdbc:mysql://localhost:3307/loginapp
spring.datasource.username=root
spring.datasource.password=your_password
```

---

### 3. Run the application

```bash
mvn spring-boot:run
```

---

### 4. Open in browser

```
http://localhost:8080/login.html
```

---

## 🔐 Authentication Flow

1. User registers
2. Password is encrypted using BCrypt
3. User logs in
4. Session is maintained securely
